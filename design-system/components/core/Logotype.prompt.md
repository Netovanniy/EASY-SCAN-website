Renders official EASY SCAN logo artwork; use it anywhere the mark appears and never set the name in ABNES instead.

```jsx
<Logotype variant="wordmark" width={240} assetBase="../../" />
<Logotype variant="monogram" width={72} strapline />
```

Variants: `wordmark` (horizontal, white, transparent), `monogram` (ES lockup, white), `monogram-black` (light backgrounds and print). `assetBase` prefixes the asset path when the consuming page is not at the project root.
