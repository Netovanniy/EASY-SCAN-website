The single action control; use `instrument` inside 3D viewers and data panels where mono type belongs, and the other three on marketing and document surfaces.

```jsx
<Button variant="primary" size="lg">Request a scan</Button>
<Button variant="secondary">View project</Button>
<Button variant="instrument" size="sm">Measure</Button>
```

One primary per view. Hover changes colour only — never size or elevation.
