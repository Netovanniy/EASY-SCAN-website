The default container for technical facts. Flat, hairline border, no shadow — cards organise information, they are not the identity.

```jsx
<SpecCard title="Capture methodology" tone="instrument"
  items={[{label:'Platform',value:'UAV LiDAR'},{label:'Flight height',value:'85',unit:'m AGL'}]}
  footer="Source: flight log · DEMO DATA" />
```
