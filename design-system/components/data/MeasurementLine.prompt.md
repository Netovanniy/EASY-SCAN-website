Annotates a real dimension on terrain imagery or a model. Position it absolutely inside a TerrainFrame overlay.

```jsx
<MeasurementLine value="184.6" unit="m" length="42%" style={{position:'absolute',left:'12%',top:'62%'}} />
<MeasurementLine kind="height" value="38.2" unit="m" orientation="vertical" length="120px" />
```
