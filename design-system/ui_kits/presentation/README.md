# UI kit — Presentation slides

PRESENTATION mode, 1280×720. One HTML file per slide type.

| File | Type |
| --- | --- |
| `title.slide.html` | Full-bleed terrain, ABNES brand statement |
| `statement.slide.html` | One idea, TacticSans, scan-grid texture |
| `process.slide.html` | Four-step process |
| `data.slide.html` | Terrain with contours, legends, measurements |
| `comparison.slide.html` | Existing vs proposed comparison seam |
| `closing.slide.html` | Proposition and next action |

ABNES appears on the title slide only. Everything structural is TacticSans;
every number, coordinate and legend is Andale Mono. Backgrounds: pure black or
full-bleed terrain — no third background colour.
