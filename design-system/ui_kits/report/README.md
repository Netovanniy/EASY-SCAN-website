# UI kit — Project report (light mode)

DOCUMENT mode validation: a technical terrain report a consultant would hand to
an architect or engineer. Light mode, 1000px document width, print-safe colours.

Carries the same typography, grid, measurement language and data palette as the
dark surfaces — only the neutrals invert (`.es-light` scope).

Sections: site map with contour plan and boundary legend · project data ·
measurement table · analysis results · accuracy and confidence, including an
explicit boundary notice.

Every value is `DEMO DATA`. The boundary notice and the confidence column are
required patterns, not decoration — an approximate boundary must never read as
legally verified.
