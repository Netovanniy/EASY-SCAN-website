# UI kit — Marketing website

Recreation of the lidareasyscan.com surfaces, rebuilt on this design system.

| File | Screen |
| --- | --- |
| `index.html` | Shell: sticky nav, page switching, footer |
| `Home.jsx` | Homepage — HERO mode, problem statement, 4-step process, LAND → SCAN pair, packages, projects teaser |
| `Gaussian.jsx` | Service page — Gaussian Splatting, EXPLANATION mode, before/after seam |
| `Projects.jsx` | Project page — LANDSCAPE → DATA → INSIGHT, DATA mode |
| `Shared.jsx` | `Section`, `SiteFooter`, `ImagePlaceholder` |

**Copy** is taken verbatim from the live site where available (hero strapline, the four process steps, the problem narrative, the three packages, the Gaussian Splatting description, the four featured scan names).

**Imagery.** Only one real EASY SCAN image was supplied (`assets/hero-terrain-scan.png`). Every other slot is an explicit `ImagePlaceholder` naming the project imagery required — nothing is faked.

**Data.** All numbers are labelled `DEMO DATA` or carry a derivation note. No survey figure here is real.
